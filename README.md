# SynthRel: Генератор синтетических реляционных данных для стресс-тестирования СУБД

> **Тема ВКР:** Разработка генератора синтетических реляционных данных для стресс-тестирования СУБД с сохранением ссылочной целостности и временных зависимостей.

---

## О проекте

Инструмент решает ключевые проблемы синтетической генерации данных для нагрузочного и стресс-тестирования современных реляционных СУБД (PostgreSQL и др.):
1. **Сохранение ссылочной целостности (Referential Integrity):** построение ориентированного графа схемы (DAG), топологическая сортировка и генерация внешних ключей с реалистичными законами распределения (Zipf / Pareto / Uniform).
2. **Сохранение причинно-следственных временных связей (Temporal Integrity):** гарантия инвариантов вида $T_{\text{событие 1}} \le T_{\text{событие 2}}$ как внутри строк, так и между связанными таблицами (цепочка: *Регистрация клиента $\to$ Оформление заказа $\to$ Оплата $\to$ Отгрузка $\to$ Доставка $\to$ Отзыв*).
3. **Высокая производительность генерации:** векторизованная генерация чисел и временных меток с помощью NumPy и потоковая выгрузка.

## Структура проекта

```text
├── configs/
│   └── ecommerce_rules.yaml    # Декларативное описание правил генерации и связей
├── schemas/
│   └── ecommerce_schema.sql    # DDL тестовой базы данных E-Commerce (ANSI / PostgreSQL)
├── src/
│   └── synthrel/
│       ├── core/
│       │   ├── models.py       # Pydantic-модели схем, полей и зависимостей
│       │   ├── graph.py        # Анализ графа зависимостей (DAG, топологическая сортировка)
│       │   └── temporal.py     # Движок расчета и валидации временных каскадов
│       ├── generators/
│       │   └── distributions.py# Векторизованные законы распределения (Zipf, Normal, Exp)
│       └── cli.py              # Консольный интерфейс Typer
├── tests/
│   └── test_graph.py           # Модульные тесты корректности топологии и временных инвариантов
├── pyproject.toml              # Метаданные пакета и зависимости
├── requirements.txt            # Список зависимостей Python
└── README.md
```

## Быстрый старт

### 1. Активация виртуального окружения
```powershell
.\.venv\Scripts\Activate.ps1
```

### 2. Запуск валидации конфигурации и расчет порядка генерации
```powershell
synthrel validate configs/ecommerce_rules.yaml
```

### 3. Экспорт графа схемы в Mermaid (для диплома и отчетов)
```powershell
synthrel export-mermaid configs/ecommerce_rules.yaml
```

### 4. Верификация 4-уровневого каскада временных зависимостей
```powershell
synthrel verify-temporal-cascade --samples 50000
```

### 5. Запуск тестов
```powershell
pytest -v
```
